## 1. 概述（约 600 字）

1.1 背景：LH001-91 是单通道差分生物电 AFE，单片只能给出 1 路差分波形
1.2 需求：标准 6 肢体导联（I / II / III / aVR / aVL / aVF）最少只需 2 路独立差分通道
1.3 方案概览：双片主从级联 —— 主片测 I（LA−RA），从片测 II（LL−RA），其余 4 路由上位机推导
1.4 关键指标一览（表格）
    - 采样率 1 kSPS/通道、24 bit、PGA×6、VREF 2.5 V、1 LSB ≈ 0.05 µV
    - SPI 6 MHz、UART 1.5 Mbps、带宽占用约 14.7 %
    - 同步方式：主片 CLKOUT 供钟 + START 引脚硬件同步
1.5 本文结构导航

## 2. 原理：为什么两片就够（约 1200 字）

2.1 LH001-91 单芯片能力边界
    - 单路差分输入 AIN0/AIN1、24 bit Σ-Δ ADC、PGA、RLD、导联脱落检测、32 级 FIFO
2.2 肢体导联与 Einthoven 定律
    - I = LA − RA，II = LL − RA，III = LL − LA
    - aVR = −(I + II)/2，aVL = I − II/2，aVF = II − I/2
    - 结论：只有 2 路独立自由度，2 片即可覆盖 6 导联（配图：Einthoven 三角 + 向量合成图）
2.3 "级联"的真实含义澄清
    - 不是数据级联（菊花链 SPI），而是**时基级联 + 通道扩展**：共享时钟、共享 START、独立片选
2.4 RA 电极复用的代价与收益
    - 收益：4 个肢体电极即可完成 6 导联，省 1 个输入通道
    - 代价：RA 同时接入两片的 AIN1，输入阻抗并联、脱落检测的激励电流需避免冲突（详见 3.5）
2.5 同/异步方案对比（表格）：双片独立晶振 / MCU 分频供钟 / 主片 CLKOUT 供钟（本方案）

## 3. 硬件设计（约 1800 字）

3.1 系统框图（配图）
3.2 引脚连接表（表格：信号名 / 主片 / 从片 / MCU 引脚 / 说明）
    - SPI 总线共享：SCK(PA5) / MISO(PA6) / MOSI(PA7)，SPI1，模式 1（CPOL=0, CPHA=1），6 MHz
    - 片选独立：CS1(PA4) → 主片，CS2(PA1) → 从片，软件 GPIO 模拟
    - 共享控制线：START(PB0)、RESET(PB8)
    - 中断线：DRDY1(PB15) 接 MCU EXTI；DRDY2(PB14) 预留未用 —— **说明为何只接一路**
    - 电极输入：LA / RA / LL，RL 由主片 RLDOUT 驱动
3.3 时钟同步设计（核心）
    - 主片 CLKCON 使能 CLKOUT → 从片外部时钟输入
    - 上电时序：先解主片、开 CLKOUT、`HAL_Delay(10)` 等时钟稳定、再解从片
    - 为什么必须同源：两片 Σ-Δ 调制器与抽取滤波器相位必须一致，否则交叉重组出的"同一时刻"不成立
3.4 基准与电源
    - 主片 BUFCON = 0x35（EN2P5 + ENREF + AVDD/2），从片 = 0x05
    - 主从参考一致性处理、去耦与布局建议
3.5 右腿驱动 RLD 的单点原则
    - 主片 RLDCON = 0x05（使能，AVDD/2 参考，fMOD/32 斩波），从片 = 0x01（关闭）
    - 若两片同时使能 RLD 会形成驱动环路，导致共模抑制恶化甚至自激
3.6 导联脱落检测的电极激励分配（表格）
    - 主片：LOC ON2 = 0x34（AIN0 拉电流 + AIN1 灌电流 + RLD 灌），LOC ON3 = 0x07（三通道全检）
    - 从片：LOC ON2 = 0x10（仅 AIN0 拉电流），LOC ON3 = 0x05（AIN0/AIN1 检测）
    - 设计理由：避免对同一电极（RA）重复施加相反方向的激励电流
3.7 PCB 与抗干扰要点
    - 模拟/数字分区、等长走线、电极防护（ESD/除颤保护）、SPI 与 ECG 走线间距

## 4. 同步与时序设计（核心章节，约 1500 字）

4.1 同步三要素：同源时钟 → 同一 START 边沿 → 同一 FIFO 复位边界
4.2 FIFO 阈值与中断节奏
    - FIFOSTA.ENOUGHCNT = 15（阈值 16 点）、INTOEN 使能 ENOUGH 中断
    - 1 kSPS → 每 16 ms 一次 DRDY，MCU 中断负载评估
4.3 成对突发读取（burst read）
    - `lh001_91_read_fifo_burst_dual_num()` 各读 16 点；tail 字段判别 EMPTY / OVERFLOW / 批尾
4.4 采样点时域交叉重组（Slot 概念）
    - 定义：1 个 Slot = 同 1 ms 时刻的（主片 6 B + 从片 6 B）= 12 B
    - 为什么在 MCU 端做：硬件无多芯片同步接口，交叉重组是"事后对齐"的唯一手段（配图：交叉重组示意）
4.5 失步检测与恢复机制
    - 判据：任一片 status ≠ OK、或两片 count 不相等、或 count = 0
    - 动作：丢弃整批 → `RST_FIFO` 命令 + 硬件 START 翻转复位双 FIFO → 计数 `fifo_recovery_count`
    - 恢复代价分析：丢失 16 ms 数据 vs 保留错位数据（宁可丢，不可错）
4.6 时序预算与抖动分析（表格 + 波形图）
    - SPI 读 16 点 × 2 片 × 7 B ≈ 224 B @ 6 MHz ≈ 0.3 ms，相对 16 ms 周期余量充足
    - DRDY 排队上限 `DRDY_PENDING_MAX = 2` 与溢出丢弃统计

## 5. 固件软件设计（约 2000 字）

5.1 软件分层：移植层（`lh001_91_port.h`）→ 驱动层（`LH001_91.c`）→ 流控层（`ecg_stream.c`）→ 应用层（`main.c`）
5.2 初始化序列（配时序图 + 代码清单）
    - 硬件复位（PDEXTRST 低脉冲 > 10 µs，等 10 ms）→ SDATAC 解锁 → USERKEY(0x86) → CLKCON → 时钟稳定等待 → 从片重复 → 导联脱落 → RLD → PGA → ADC → ADCCHCON → FIFO 配置 → START
    - 顺序依赖说明：哪些步骤不能换序
5.3 主从差异化配置对照表（**重点表格**，18 个寄存器 Master vs Slave）
    - CONFIG1 / LOCON1-3 / RLDCON / BUFCON / ADCCHCON / ADCCTRL / PGAGAIN / PGACTRL / PGACTRL1 / SYSCLK / MODCLK / CLKCON / SPICTRL / INTOEN / FIFOSTA
    - 附 `main.c` 中寄存器 Dump 打印的实际验证输出
5.4 生产者—消费者模型
    - 生产者：EXTI(DRDY) 只做 `fifo_irq_pending++`，主循环执行 `fifo_service_once()`（中断内不做 SPI 读）
    - 消费者：TIM6（240 MHz/240 → 1 MHz，ARR 初值 999）1 ms 中断泵送 1 个 Slot
    - 环形缓冲：64 Slot × 12 B，无锁单生产者/单消费者
5.5 自适应水位控制（配图：控制框图）
    - 目标水位 24，一阶滤波 `avg = avg*0.85 + cur*0.15`
    - P 调节：ARR = 999 − 0.5 × err，限幅 994～1004（±0.5 %）
    - 作用：吸收芯片时钟与 MCU 时钟的 ppm 偏差，避免缓冲长期漂移到溢出或断流
5.6 异常处理与可观测性
    - 统计量：`slots_published / slots_sent / overflow_count / tx_error_count / fifo_recovery_count / drdy1_irq_count`
    - DMA 发送权 `tx_busy` 的原子抢占、发送失败重发策略
5.7 内存与 Cache 一致性
    - MPU 配置、AXI SRAM 非缓存属性、`tx_frame` 32 B 对齐的必要性
5.8 关键代码清单（3～4 段，带注释）：`LH001_91_App_Init` / `fifo_service_once` / `ecg_stream_pump_slot` / `HAL_GPIO_EXTI_Callback`

## 6. 数据链路与通信协议（约 1200 字）

6.1 帧格式定义（**重点表格**）
    - SOF(2B: A5 5A) + VERSION(1B: 0x01) + SLOT_COUNT(1B) + SEQ(4B, LE) + PAYLOAD + CRC16(2B, LE)
    - CRC-16/CCITT-FALSE：poly 0x1021，init 0xFFFF，覆盖 [VERSION .. PAYLOAD 末]
6.2 采样点 6 字节解析（配位域图）
    - START[3:0] / LOFFSTAT[5:0] / GPIO[1:0] / DATA[23:0] / TAIL[1:0]
    - 24 位有符号扩展；TAIL 编码 01=批尾、02=空、03=溢出
6.3 解交叉语义：同一 Slot 内主从两点采自同一 1 ms 时刻
6.4 带宽核算（计算过程）
    - 22 B × 1000 帧/s = 22 kB/s ≈ 220 kbps（8N1），占 1.5 Mbps 的 14.7 %
    - 波特率选型依据与余量
6.5 上位机接收与解析流程（配流程图）
    - 环形接收缓冲（8 KB 上限）→ SOF 同步 → CRC 校验 → 解交叉 → 队列（上限 200 批）→ 30 FPS 批量刷新
    - SEQ 连续性检测丢帧
6.6 常见链路故障与定位（乱码 / 卡顿 / 断连自动退出，连续 20 次异常判定掉线）

## 7. 6 导联合成与信号处理（约 1200 字）

7.1 码值 → 电压换算
    - `mV = code × VREF / (2^23 − 1) / PGA_GAIN`
    - **注意**：固件 `ADC_REF_MV = 2510` 与上位机 `VREF_MV = 2500` 不一致，需统一（误差约 0.4 %）
7.2 六导联向量运算（公式 + 系数矩阵表）
    - I = M，II = S，III = II − I，aVR = −(I + II)/2，aVL = I − II/2，aVF = II − I/2
7.3 实时滤波链（开关式组合）
    - 高通（去基线漂移）/ 50 Hz 陷波（去工频）/ 低通（去肌电与高频噪声）
7.4 导联脱落状态映射与消抖
    - LOFFSTAT 位 → 电极语义（主片 AIN0=LA / AIN1=RA / RLD；从片 AIN0=LL / AIN1=RA）
    - 批内按位或融合 + 0.4 s 滞后保持消抖（解决悬空导联线受 50 Hz 感应导致的位跳变）
7.5 显示与标定
    - 走速 25 mm/s、增益 10 mm/mV 的换算，Y 轴 Code/mV 切换
    - 用 `ecg_standard_data.csv` 与软件模拟器做无硬件自测
